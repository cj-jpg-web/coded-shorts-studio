# Portable anatomy-animation production skill

Start with [SKILL.md](skills/direct-anatomy-animation/SKILL.md). The skill contains production rules, art direction, performance/timing guidance, recorded reference observations, review gates, an experiment template, and an evolving learning ledger.

## Use with any AI

Give the AI access to this private repository, or clone/download it and attach the skill folder. A link alone will not work if that AI cannot access private GitHub content.

Paste this instruction:

> Read skills/direct-anatomy-animation/SKILL.md and its learning ledger before working. Follow the relevant references. State the baseline and unresolved gaps, then carry out my request. After reviewing an output, record evidence, my feedback, remaining issues, and supported lessons. Save authorized updates back to this repository and verify the revision. If you cannot write here, provide an unapplied patch and say it is unsaved.

For AI tools that support skill installation, use the complete skills/direct-anatomy-animation folder. For tools that only accept prompts or file attachments, provide SKILL.md plus the referenced Markdown files. agents/openai.yaml is optional tool-specific metadata; the production instructions do not depend on it.

## Durable knowledge

This GitHub copy is the source of truth. It is plain text and can be read locally without a ChatGPT account. It does not require ChatGPT Library access; optional baseline locating hints are included only for recovery.

The skill is a production workflow and knowledge base, not an animation engine or a guarantee of reference-quality output. The current baseline still has documented gaps.

Before each session, read the latest revision. After experiments, keep full records beside project source and append concise reusable lessons to the skill ledger. Separate user requirements, observations, hypotheses, failed approaches, and validated lessons. Do not overwrite concurrent changes or record hypothetical tests as completed.

An installed copy in an AI tool is a snapshot. Update it deliberately from GitHub after changes; neither GitHub nor the file format makes an AI remember or synchronize automatically. Repository history preserves earlier versions.

This repository remains private. Do not change visibility or redistribute third-party reference clips without the owner's instruction.
